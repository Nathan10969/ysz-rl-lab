## 2. 研究问题与方法谱系

研究问题：**冻结物理评分器、限制实际物理计算时，不同强度的策略改进，哪一种更有效？更强优化是否放大MACE与DFT的偏差？**

| 学习臂 | 数据和更新 | 比较目的 |
|---|---|---|
| SFT初始化后冻结、多采样 | 教师D0完成后不更新模型，继续搜索 | 相同计算用于更多尝试是否已经足够 |
| 迭代SFT（筛选式策略改进） | 自采样，按完整回合回报筛选后模仿；D0/早轮回放 | 二值筛选、自训练的收益 |
| 回合级GRPO，主RL臂 | 同起点G=4条K=8步回合，用组内完整回报算优势 | 在线策略梯度的收益 |
| 步级GRPO，必做消融 | 同状态4个动作，按即时能差比较 | 局部即时奖励与回合回报的差别 |
| DPO，可选 | 同起点好/坏回合成对，离线偏好训练 | 使用坏经验的机制对照 |

论文采用“SFT初始化 → 筛选式自训练 → 偏好优化 → 在线策略梯度”的谱系，不把迭代SFT绝对排除出广义RL。ReST明确属于自采样加离线策略改进；GRPO提供组内比较而不另训critic。这里只支持方法分类，不预设GRPO在0.6B或YSZ上更稳、更好。[ReST](https://arxiv.org/abs/2308.08998)、[DeepSeekMath §4.1/§5.2](https://arxiv.org/html/2402.03300v3)、[DPO](https://arxiv.org/abs/2305.18290)。

四个必做学习臂每seed从**同一个通过合法率闸门的SFT checkpoint、tokenizer/template与环境版本**分叉。SFT参考固定；GRPO old policy仅每次采样批次更新，二者不混用。另保留SA/GA/CE中由验证集预选的最强纯搜索，获得同样可见物理信息、动作规则和物理预算；纯搜索没有SFT权重，起点几何与评估协议相同。独立采集一次SFT、同数据一次SFT、搜索蒸馏、非语言策略为扩展控制，原60/162卡时矩阵已被本版取代，均未获执行授权。

## 3. 环境v2：末态驱动的局部动作

环境协议记为 `YSZ08_terminal_local2_v1`，详见 [TRAINING_ENV_SPEC.md](TRAINING_ENV_SPEC.md)。相较旧版，下一动作作用于当前**弛豫末态占位**，且交换限制在对应子晶格前两配位壳；所有比较臂一起更换，不能把新旧环境成绩拼成学习曲线。既有DFT和633/635任务不因此修改。

主任务为固定15.42 Å立方胞：108阳离子位、216氧位；Zr92Y16O208，316原子、8空位。状态保存当前末态占位z、实际几何R与能量E、当前最低能量B、剩余步数/预算、最近3步动作与能差，以及回合已访问末态集合。LLM观察是这些量的紧凑JSON摘要，不含DFT标签。

动作仍为严格JSON `swap_cations`（Y/Zr）或 `move_vacancy`（空位/O）；位点须属于同一母子晶格，周期性最小像距离不超过该子晶格第二壳。由reference(3)免费计算：阳离子两壳3.63452886/5.14 Å，阴离子两壳2.57/3.63452886 Å；不按缺陷结构重定义邻居。动作改变z得到请求占位c；从标准理想母晶格重建c，再按固定MACE协议弛豫并投影得到新的z。初版不继承上一帧连续几何，确保请求确定性；R仍保留供末态记录和DFT输入。K=8包含非法、重复和失败尝试。

缓存不能提前知道未知请求会落入哪个末态。先以成分/胞/实际编号请求占位/模型与弛豫协议查已核验的 `request→(terminal_key,R,E)` 映射，命中才省去弛豫；未命中必须算，事后若终态重复，仍记已执行成本。同末态key下不同几何盆地保留geometry hash与能差，不覆盖。对称缓存只有保存正逆变换且坐标/动作编号可还原才可命中。各arm/seed缓存隔离；共同D0明确共享并归因，不能偷用其他臂新发现。

## 4. 奖励和回报的确切口径

有效新结果：`B_t=min(B_(t-1), E_t)`。

```text
r_energy,t = (B_(t-1)-B_t) / 0.20 eV
r_novel,t  = 0.05，若本回合首次到达有效新terminal_key，否则0
r_invalid,t = -1，若动作非法，否则0
r_t = r_energy,t + r_novel,t + r_invalid,t
R_episode = sum(r_t)，gamma=1
```

0.20 eV只是按现有约0.195 eV/胞相对能RMSE选的奖励尺度，不是误差界或真实收益门槛。代理解释门槛仍为 **δ_proxy≥0.30 eV/胞**，主比较仍为等额k=5的独立DFT低能率。

**只有能量项**满足 `sum(r_energy)=(B_0-B_K)/0.20`；总回报还包含新颖性与非法项，不能把三者总和说成纯能量降幅。奖励分量分别保存和画图，跨位、旋转/平移等价访问只按末态canonical key认一次。回合初态在访问集合内，不给初态新颖性分。每个同起点组开始前冻结该arm/seed历史末态集合V；四条回合分别复制同一V并各自增加回合内已见key。只有不在V也未在本回合出现的末态给分，四条都收齐后才把新key并入全局V，避免执行先后影响组内回报；以后组重复访问不再给新颖性。组顺序由封存种子确定。

升能步骤的能量奖励为0；记录新的最低能量才得能量分，因此原地循环不能刷能量分。有限状态/已计末态重复也不能刷新颖性。非法不调MACE、消耗一步和token，给−1。合法但弛豫失败/未收敛/映射模糊的尝试记成本、状态保持、训练奖励暂定−1（与非法分量分列），不得把最后一帧当低能结果。预算截断的未完成回合保留日志；不混进完整回合的组内优势。

## 5. GRPO与DPO的更新合同

正式设计目标每轮16个起点/组，各采4条完整8步轨迹，共64回合、512次动作；未达时间/合法率要求则报告实际完成量。唯一冒烟650保持4组/16回合/128动作上限。不同起点不能拼在同一优势组。

```text
A_i = (R_i - mean(R_group)) / max(std_population(R_group), 1e-8)
rho_token = exp(logp_current - logp_old)
L_PG = -mean_episode[mean_action_token(min(rho*A, clip(rho,0.8,1.2)*A))]
L = L_PG + 0.03 * mean_action_token(KL_to_frozen_SFT)
```

KL系数预登记0.03，在审核建议0.02–0.05范围内；clip=.2。每回合先对所有有效生成动作token（含动作结束符）平均，再对回合/起点平均，避免长输出额外加权。prompt、系统模板、环境返回、历史观察和padding全部mask。KL也只对动作token；参考分布来自固定SFT适配器，不能简单关掉LoRA就把原始基座误称SFT参考。每次更新冻结采样old log-prob，不能在梯度中重算old；GRPO无需价值网络，不代表内存和稳定性已实测。

组标准差≤1e-8时该组A=0；不反复采样凑方差。若所有组无有效优势，记录 `NO_UPDATE_ZERO_GROUP_VARIANCE`，不伪造一次成功更新。正/负优势符号、loss/梯度/参数变化、KL、old/reference checkpoint SHA都进入审计。初始冒烟仅1次optimizer更新，lr=1e-5、clip_grad_norm=1，沿用LoRA r16/alpha32/dropout.05 q/v；采样及log-prob评估统一eval模式避免dropout破坏比值，eval模式下仍允许梯度。正式优化步数由下表限制，不能因零方差临时把G改成8。

步级消融在同一状态采4个单步分支，以 `(E_current-E_next)/0.20` 为即时能量奖励（允许负值），新颖性/非法处理同主臂；只对这4个同状态分支算优势。每步按预先随机流均匀选一个分支继续，不能总选奖励最高者造成额外搜索优势。8个状态×4分支也是32个动作弛豫上界。它同时改变奖励范围和访问轨迹分布，不能把差异全部解释成唯一的“信用分配效应”；若要单独隔离回报范围，另设计同轨迹return-to-go控制并单独审核。

迭代SFT每起点4条中取完整回报最高1条，平局按轨迹hash，先按末态家族去重；保留有价值的升能中间步。R1按seen-token回放50%D0+50%新轮，R2为25%D0+25%R1+50%R2；有效样本不足则缩量并报告，不用DFT选样或放宽门槛。

可选DPO按同起点、同预算长度、完整有效回合的物理回报形成好/坏对，等分或不完整不成对；模型概率只累计动作token，环境反馈不作为模型target。优先复用迭代SFT已有数据，必须记录数据来源和产生该数据所需完整策略/物理成本；其“几乎零新增MACE”仅指共享后的物理增量，不是免费获得信息或等成本在线胜负。不得把DPO donor轨迹的物理成本移除后再给它完整额外搜索配额。

## 8. 每轮DFT诊断、代理过度优化与多样性

每个arm、每seed、每轮各取**5个不同有效末态**：能量最低3个、按固定hash随机1个、在剩余中末态壳统计最远1个；顺序冲突按预登记key排序补齐，缺额如实报告，不新增免费搜索。D0共有checkpoint的5个诊断可共享实际计算，归因仍列每臂；R1/R2全部臂（包括冻结与强搜索）在相同物理预算刻度审计。诊断家族不进入训练/盲评，诊断结果不用于挑更新或早停获胜点；仅既定异常阈值可触发停止审阅。

核心5臂×3seed×2轮×5=150，另共享D0 3×5=15，最多**165个DFT诊断名额**；可选DPO再加30为195。原审核08“4臂×4轮×5=80/seed、约6卡时”是另一规模的算术示例，不能当本两轮包实测费用。冻结审核06大胞16个Γ单点的父账实耗均值0.072517361卡时/项，按相同协议线性缩放，165个诊断约11.965卡时，195个约14.141；这是校准样本外推，不是新分布保证。G3三构型最大相对变化0.01999865≤.05，仅支持该三点Γ/k222检查；G2未通过简化终评门槛，故这些单点只作诊断，最终盲评须完整弛豫。**没有授权新增这些DFT作业**。

物理增益曲线用同一封存参考的 `gain_MACE` 与 `gain_DFT`（eV/胞）并列，另画二者之差随轮次/实际弛豫次数变化；不把含新颖性/KL的训练回报当物理能量。逐轮报告力误差、跨位/匹配距离、NN/NNN与低能尾部偏差。MACE的校准RMSE不是新分布误差界；“过度优化”是否出现由诊断测量决定，不预写结论。

多样性同时报告：固定预算下未经去重top-5里的独特末态key数、去重后能否填满5个候选、全搜索独特末态数/访问频率/熵、top-5不同Y–空位NN/NNN向量数。只统计去重后5个的key数恒为5，没有检测意义。对称等价、同key几何冲突与重复占位分别记录。任何不足5个仍以5为终评分母。

## 9. 最终盲评与L1零样本迁移
