# 一次原子动作，怎样成为一条强化学习经验？

强化学习在这里的用途是：根据已有经验，改善下一次选择动作的方式。先把一次尝试完整走通。

## 输入：当前是什么结构？

**状态（state）**记录当前结构和搜索上下文，包括哪些母晶格位置放 Y、哪些位置是氧空位，以及当前能量、历史最好能量和剩余步数。主体系有 324 个母晶格位置，其中 8 个是空位，所以真实原子数是 316。

**动作（action）**是一条具体指令。例如，把某个空位与允许范围内的氧原子交换。动作必须保持组成，并满足子晶格和距离限制。

代码入口：[validate_occupancy / enumerate_legal_actions](../../research/formal12/scripts/claude08_env.py)。

## 执行：动作后的能量由谁决定？

环境施加动作，按协议构造待弛豫结构，加入固定种子控制的微小扰动，再调用 MACE 做弛豫。**弛豫**就是让原子沿降低力的方向移动，尝试到达附近较稳定的位置。

随后检查收敛性，并把末态分配回母晶格。只有经过这一步，才知道下一步实际从什么结构出发。失败尝试也消耗计算；回滚和零奖励不能当作免费尝试。

代码入口：[FormalEnvironment 与 Physics](../../research/formal12/scripts/formal12_rl.py)。

## 输出：新状态、奖励和计数器

**奖励（reward）**告诉训练方法这次尝试获得了什么。该项目的一部分奖励来自“刷新历史最好能量”，而不是每一步下降多少都一律加分。

例子：原来的最好能量是 −100 eV，新结构是 −100.2 eV，刷新了 0.2 eV；按 0.20 eV 的尺度归一化，能量奖励为 1。若另一个结构比当前结构低，但仍高于历史最优，则不会刷新这个能量奖励。新颖性奖励是另外一项，需要单独追踪。

计数器记录动作尝试、真实弛豫、结构能量／力调用、前向调用及 token。预算是实验公平性的一部分。

## 用项目检查自己的理解

- 当前能量与历史最好能量为什么要同时保存？
- 请求中的占位和弛豫后重新映射的占位可能不同，下一步应该用哪一个？
- 一次失败的物理尝试为什么仍应计费？

这些问题对应已有环境与预算测试，见 [研究测试目录](../../research/tests/)。
