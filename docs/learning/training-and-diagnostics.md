# 从本轮实验理解：偏好、降能与递归改进

这些是从已完成实验整理的学习材料，不代表个人已经完成相应课程或掌握考核。

## 模型开始偏向某个选项，意味着什么

想象一份有 16 个候选动作的菜单。贪心公式会给出一个便宜的排序，模型则给每项分配概率。C 衡量模型在这份公式上，取得了多少随机选择到贪心选择之间的分数改善。

网格中 C 从约 0.022 上升到 0.406，说明选择分布已经形成可观察的偏好。实际材料能量仍由执行动作后的 MACE 弛豫决定；便宜公式并非真实能量，所以还要运行物理评估。

对应的 [C 公式与数据](../experiments/menu-grid-2026-10-28.md) 中，C=0.406 的模型首选命中率只有约 26.9%。两者衡量的对象不同。

## 为什么不能只用“学习率乘步数”解释

学习率控制优化器更新的尺度，更新频率还会影响批次组合和策略刷新。网格里 5e-5×16 与 1e-4×8 的乘积相同，C 却约为 0.107 与 0.023。一个乘积不足以预测学习效果。

每个配置只有一个主要训练重复，不能据此确定最优学习率或唯一失败原因。继续在线训练还会收集新状态和奖励；更多步后的改善同时包含了更多数据的影响。

## 开发数据和最终检验各做什么

984 的菜单曾用于模仿检验，后来又用于门控和选参，因此已经是开发数据。开发数据帮助挑方案；最后的研究结论要由没有参与这些选择的评价证据支撑。

只用两次重复的差设置工程门槛，可以帮助控制预算，但两次结果不足以估计整个训练过程的噪声分布。也不能把达到探索门槛写成已完成显著性检验。

## 训练搜索模型和 RSI 的递归发生在哪里

GRPO 根据既定损失更新搜索策略。RSI 工程小试另有一个提出改进的程序 M，并允许递归组形成 M1，再由 M1 接手下一代。要检验它是否“更会改进”，还需要与固定 M 的对照和共同起点的重置比较。

两条工作可以同时进行，但 C 的上升本身不能证明递归收益。[当前小试状态](../experiments/rsi-pilot-status.md)
