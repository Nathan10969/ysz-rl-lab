# GitHub 发布与日更计划

用户已选择公开仓库，并授权每天 America/Los_Angeles 20:00 整理和同步有证据的新进展。

## 目标

建立个人主导、AI 协作的 YSZ 强化学习研究项目。首页可快速理解用途，历史可追溯，代码可阅读，小规模 CPU 检查可执行。
首版只记录实际开展的 SFT、GRPO、物理校准、约束解码和候选菜单工作。

## 文件职责

- README.md：研究问题、已验证结果、路线图、个人角色与阅读入口。
- docs/experiments/：实验设计、时间线和结果判读。
- docs/learning/：从本项目实际问题整理的 RL 概念、代码入口和待回答问题。
- history/：原有计划、审核、失败记录、归档版本的脱敏副本。
- research/：项目自有 Python 源码和已有测试，保留原相对层级。
- experiments/：从现存 result.json 提取的逐起点指标、计数器、来源哈希。
- journal/：按日期记录；回溯整理与当天新增记录明确区分。
- tools/：白名单导出、公开文件检查、离线结果复算。

## 日更边界

只读取本机已有结果，不查询集群，不执行历史提交脚本，不启动训练、MACE、DFT 或 MD。
新结果要核对指标、比较对象和状态；学习收获不能由程序冒充个人已掌握的内容。
先导出并检查，再提交、推送；没有变化不制造空提交。新增公开文件须先审查再加入白名单。
原始研究目录不被发布工具改写，原始证据与公开副本的映射写入 provenance/manifest.json。
